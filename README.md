# تَحَقَّق | Tahaqqaq Security

منصة أولية لتسجيل المستخدمين وفحص سمعة الروابط والملفات عبر VirusTotal.
صممت بواسطة محروس باحسين.

## متغيرات البيئة المطلوبة
- SECRET_KEY: سر قوي لجلسات Flask.
- VT_API_KEY: مفتاح VirusTotal محفوظ في إعدادات الخادم، لا تضعه في GitHub.
- DATABASE_URL: رابط قاعدة بيانات PostgreSQL للإنتاج.

## التشغيل المحلي
أنشئ بيئة افتراضية وثبت requirements.txt ثم عيّن متغيرات البيئة وشغّل:
python app.py

## تنبيهات قبل الإطلاق العام
هذا نموذج أولي وليس جاهزاً للإطلاق العام دون مراجعة أمنية واختبارات إضافية.
تحقق من شروط ترخيص VirusTotal؛ مفتاح API المجاني الشخصي لا يمنح تلقائياً حق تشغيل خدمة عامة متعددة المستخدمين.
رفع الملفات إلى VirusTotal قد يتيح تخزينها أو مشاركتها وفق شروط الخدمة؛ لا ترفع ملفات سرية.
أضف قبل الإطلاق: تحقق البريد، تحديد معدل الطلبات، حماية من إساءة الاستخدام، سياسة خصوصية، شروط استخدام، ومراقبة تكاليف وحدود API.
